---
title: Button Group
description: Groups related buttons together with shared borders and consistent styling.
---

## Installation

```bash
npx shadcn@latest add "https://ora-ui.com/r/button-group.json"
```

## Usage

```tsx
import { ButtonGroup, ButtonGroupSeparator, ButtonGroupText } from '@/components/ui/button-group';
import { Button } from '@/components/ui/button';

<ButtonGroup>
  <Button variant="surface">One</Button>
  <Button variant="surface">Two</Button>
  <Button variant="surface">Three</Button>
</ButtonGroup>;
```

## Props

### ButtonGroup

| Prop          | Type                         | Default        |
| ------------- | ---------------------------- | -------------- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |
| `className`   | `string`                     | —              |

All other props are forwarded to the underlying `<div>` element.

### ButtonGroupSeparator

| Prop          | Type                         | Default      |
| ------------- | ---------------------------- | ------------ |
| `orientation` | `"horizontal" \| "vertical"` | `"vertical"` |
| `className`   | `string`                     | —            |

All other props are forwarded to the [Separator](/docs/components/separator) primitive.

### ButtonGroupText

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | —       |

All other props are forwarded to the underlying `<div>` element.
