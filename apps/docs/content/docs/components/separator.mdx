## Installation

```bash
npx shadcn@latest add "https://ora-ui.com/r/separator.json"
```

## Usage

```tsx
import { Separator } from '@/components/ui/separator';

export default function Example() {
  return <Separator />;
}
```

The default orientation is `horizontal`. Use `orientation="vertical"` for vertical dividers.

## API Reference

| Prop          | Type                         | Default        |
| ------------- | ---------------------------- | -------------- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |
| `className`   | `string`                     | —              |

All other props are forwarded to the underlying [Base UI Separator](https://base-ui.com/components/separator) primitive.
