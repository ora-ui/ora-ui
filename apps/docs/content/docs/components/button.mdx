---
title: Button
description: Triggers an action or event, such as submitting a form or opening a dialog.
---

## Installation

```bash
npx shadcn@latest add "https://ora-ui.com/r/button.json"
```

## Usage

```tsx
import { Button } from '@/components/ui/button';

<Button>Button</Button>;
```

## Variants

The `variant` prop controls the visual style of the button.

<div className="flex gap-2">
  <Button variant="solid">Solid</Button>
  <Button variant="outline">Outline</Button>
  <Button variant="surface">Surface</Button>
  <Button variant="soft">Soft</Button>
  <Button variant="ghost">Ghost</Button>
</div>

```tsx
import { Button } from '@/components/ui/button';

export default function ButtonVariants() {
  return (
    <div className="flex gap-2">
      <Button variant="solid">Solid</Button>
      <Button variant="outline">Outline</Button>
      <Button variant="surface">Surface</Button>
      <Button variant="soft">Soft</Button>
      <Button variant="ghost">Ghost</Button>
    </div>
  );
}
```

## Theme

The `theme` prop applies a color scheme across all variants.

<div className="flex gap-2">
  <Button variant="solid" theme="gray">
    Gray
  </Button>
  <Button variant="solid" theme="accent">
    Accent
  </Button>
  <Button variant="solid" theme="destructive">
    Destructive
  </Button>
</div>

```tsx
import { Button } from '@/components/ui/button';

export default function ButtonTheme() {
  return (
    <div className="flex gap-2">
      <Button variant="solid" theme="gray">
        Gray
      </Button>
      <Button variant="solid" theme="accent">
        Accent
      </Button>
      <Button variant="solid" theme="destructive">
        Destructive
      </Button>
    </div>
  );
}
```

## With Icon

Icons can be placed alongside button text. The button handles icon sizing automatically.

<div className="flex gap-2">
  <Button>
    <PlusCircleIcon />
    Create New
  </Button>
  <Button variant="soft">
    <CloudArrowUpIcon />
    Upload
  </Button>
</div>

```tsx
import { CloudArrowUpIcon, PlusCircleIcon } from '@heroicons/react/16/solid';
import { Button } from '@/components/ui/button';

export default function ButtonWithIcon() {
  return (
    <div className="flex gap-2">
      <Button>
        <PlusCircleIcon />
        Create New
      </Button>
      <Button variant="soft">
        <CloudArrowUpIcon />
        Upload
      </Button>
    </div>
  );
}
```

## Props

| Prop        | Type                                                     | Default   |
| ----------- | -------------------------------------------------------- | --------- |
| `variant`   | `"solid" \| "outline" \| "surface" \| "soft" \| "ghost"` | `"solid"` |
| `theme`     | `"gray" \| "accent" \| "destructive"`                    | `"gray"`  |
| `className` | `string`                                                 | —         |

All other props are forwarded to the underlying [Base UI Button](https://base-ui.com/components/button) primitive.
