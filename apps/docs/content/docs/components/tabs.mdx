## Usage

```tsx
import { Tabs, TabsSurface, TabsList, TabsTab, TabsPanel } from '@/components/ui/tabs';

<Tabs defaultValue="overview">
  <TabsList>
    <TabsTab value="overview">Overview</TabsTab>
    <TabsTab value="analytics">Analytics</TabsTab>
    <TabsTab value="reports">Reports</TabsTab>
  </TabsList>
  <TabsPanel value="overview">Overview content</TabsPanel>
  <TabsPanel value="analytics">Analytics content</TabsPanel>
  <TabsPanel value="reports">Reports content</TabsPanel>
</Tabs>;
```

## API Reference

### TabsList

| Prop         | Type                | Default  |
| ------------ | ------------------- | -------- |
| `variant`    | `"soft" \| "solid"` | `"soft"` |
| `track`      | `boolean`           | `true`   |
| `transition` | `boolean`           | `false`  |

For the remaining sub-components (`Tabs`, `TabsTab`, `TabsPanel`), all props are forwarded to the corresponding Base UI primitives. See the [Base UI Tabs API Reference](https://base-ui.com/react/components/tabs#api-reference).
