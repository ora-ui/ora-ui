## Props

### Badge

| Prop        | Type                                                            | Default     |
| ----------- | --------------------------------------------------------------- | ----------- |
| `variant`   | `"solid" \| "soft" \| "outline" \| "surface"`                   | `"soft"`    |
| `size`      | `"default" \| "icon"`                                           | `"default"` |
| `theme`     | `"gray" \| "accent" \| "destructive" \| "warning" \| "success"` | `"gray"`    |
| `render`    | `React.ReactElement`                                            | `<span>`    |
| `className` | `string`                                                        | —           |

All other props are forwarded to the rendered element.
