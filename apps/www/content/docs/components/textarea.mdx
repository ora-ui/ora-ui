## Usage

```tsx
import { Textarea } from '@/components/ui/textarea';

<Textarea placeholder="Write something..." />;
```

## Examples

### Variant

The `variant` prop controls the visual style of the textarea.

<ComponentPreview name="textarea-variant" select={['surface', 'outline', 'soft']} />

### Manual resize

Set `autoResize={false}` to disable auto-grow and let the user resize via the drag handle. Note that `field-sizing: content` requires a [modern browser](https://caniuse.com/mdn-css_properties_field-sizing) — `autoResize` defaults to `true` but falls back gracefully where the property is unsupported.

<ComponentPreview name="textarea-manual-resize" />

### With label

Use `Field` and `FieldLabel` to associate a label with the textarea.

<ComponentPreview name="textarea-with-label" />

### With button

Compose with `Button` inside a `Field` to add a submit action.

<ComponentPreview name="textarea-with-button" />

## API Reference

| Prop         | Type                               | Default     |
| ------------ | ---------------------------------- | ----------- |
| `variant`    | `"surface" \| "outline" \| "soft"` | `"surface"` |
| `autoResize` | `boolean`                          | `true`      |

All other props are forwarded to the underlying `<textarea>` element.
