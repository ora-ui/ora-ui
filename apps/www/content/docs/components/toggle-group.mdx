## Usage

```tsx
import { ToggleGroup, ToggleGroupItem } from '@/registry/ui/toggle-group';

<ToggleGroup>
  <ToggleGroupItem value="a">A</ToggleGroupItem>
  <ToggleGroupItem value="b">B</ToggleGroupItem>
  <ToggleGroupItem value="c">C</ToggleGroupItem>
</ToggleGroup>;
```

## API Reference

### ToggleGroup

| Prop          | Type                             | Default        |
| ------------- | -------------------------------- | -------------- |
| `variant`     | `"soft" \| "outline" \| "solid"` | `"soft"`       |
| `size`        | `"sm" \| "md" \| "lg"`           | `"md"`         |
| `spacing`     | `number`                         | `0`            |
| `orientation` | `"horizontal" \| "vertical"`     | `"horizontal"` |
| `className`   | `string`                         | —              |

### ToggleGroupItem

Inherits `variant` and `size` from the parent `ToggleGroup` context. Individual items can override either prop directly.

All other props are forwarded to the underlying [Base UI Toggle](https://base-ui.com/react/components/toggle) primitive.
