## Usage

```tsx
import { Toggle } from '@/registry/ui/toggle';

<Toggle aria-label="Toggle bold">
  <BoldIcon />
</Toggle>;
```

## Examples

### Variant

The `variant` prop controls the visual style of the toggle.

<ComponentPreview name="toggle-variant" select={['soft', 'outline', 'solid']} />

## API Reference

| Prop      | Type                             | Default  |
| --------- | -------------------------------- | -------- |
| `variant` | `"soft" \| "outline" \| "solid"` | `"soft"` |

All other props are forwarded to the underlying [Base UI Toggle](https://base-ui.com/react/components/toggle) primitive.
