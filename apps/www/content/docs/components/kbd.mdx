## API Reference

### Kbd

| Prop        | Type                             | Default  |
| ----------- | -------------------------------- | -------- |
| `variant`   | `"ghost" \| "soft" \| "surface"` | `"soft"` |
| `className` | `string`                         | —        |

All other props are forwarded to the underlying `<kbd>` element.

### KbdGroup

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | —       |

All other props are forwarded to the underlying `<div>` element.
