## API Reference

| Prop        | Type                 | Default     |
| ----------- | -------------------- | ----------- |
| `size`      | `"default" \| "sm"`  | `"default"` |
| `theme`     | `"gray" \| "accent"` | `"gray"`    |
| `className` | `string`             | —           |

All other props are forwarded to the underlying [Base UI Switch](https://base-ui.com/react/components/switch) primitive.
