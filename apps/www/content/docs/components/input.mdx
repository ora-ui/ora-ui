## Examples

### Variant

The `variant` prop controls the visual style of the input.

<ComponentPreview name="input-variant" select={['surface', 'outline', 'soft']} />

## API Reference

| Prop        | Type                               | Default     |
| ----------- | ---------------------------------- | ----------- |
| `variant`   | `"surface" \| "outline" \| "soft"` | `"surface"` |
| `className` | `string`                           | —           |

All other props are forwarded to the underlying [Base UI Input](https://base-ui.com/react/components/input) primitive.
