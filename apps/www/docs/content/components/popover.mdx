## Usage

```tsx
import {
  Popover,
  PopoverContent,
  PopoverDescription,
  PopoverHeader,
  PopoverTitle,
  PopoverTrigger,
} from '@/registry/ui/popover';

<Popover>
  <PopoverTrigger render={<button>Open</button>} />
  <PopoverContent>
    <PopoverHeader>
      <PopoverTitle>Title</PopoverTitle>
      <PopoverDescription>Description</PopoverDescription>
    </PopoverHeader>
  </PopoverContent>
</Popover>;
```

## Examples

### Placement

Set `side` and `align` on `PopoverContent` to choose where the popover opens. It flips to the opposite side when there is no room.

<ComponentPreview name="popover-placement" select={['top', 'right', 'bottom', 'left']} />

### Open on hover

Pass `openOnHover` to `PopoverTrigger` to open the popover when the trigger is hovered. Use `delay` and `closeDelay` to tune the timing.

<ComponentPreview name="popover-open-on-hover" />

### Form

A popover can hold interactive content such as a small form. Focus moves into the popover when it opens.

<ComponentPreview name="popover-form" />

### Modal

Pass `modal` to `Popover` to lock page scroll and block interaction outside it. Base UI traps focus only when a `PopoverClose` is rendered inside the content, so include one.

<ComponentPreview name="popover-modal" />

## API Reference

### PopoverContent

#### Structure

| Prop          | Type                                                                       | Default    |
| ------------- | -------------------------------------------------------------------------- | ---------- |
| `side`        | `"top" \| "right" \| "bottom" \| "left" \| "inline-start" \| "inline-end"` | `"bottom"` |
| `sideOffset`  | `number`                                                                   | `4`        |
| `align`       | `"start" \| "center" \| "end"`                                             | `"center"` |
| `alignOffset` | `number`                                                                   | `0`        |

#### Behavior

| Prop              | Type      | Default |
| ----------------- | --------- | ------- |
| `showCloseButton` | `boolean` | `false` |

### PopoverHeader

A flex column that spaces `PopoverTitle` and `PopoverDescription`. It is Ora only and has no Base UI counterpart.

Slots are `popover`, `popover-trigger`, `popover-content`, `popover-header`, `popover-title`, `popover-description` and `popover-close`.

All other props are forwarded to the underlying [Base UI Popover](https://base-ui.com/react/components/popover) primitive.
