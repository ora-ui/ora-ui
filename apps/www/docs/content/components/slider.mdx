## Usage

```tsx
import {
  Slider,
  SliderLabel,
  SliderValue,
  SliderControl,
  SliderTrack,
  SliderIndicator,
  SliderThumb,
} from '@/registry/ui/slider';

<Slider defaultValue={40}>
  <SliderLabel>Volume</SliderLabel>
  <SliderValue />
  <SliderControl>
    <SliderTrack>
      <SliderIndicator />
    </SliderTrack>
    <SliderThumb aria-label="Volume" />
  </SliderControl>
</Slider>;
```

## API Reference

### Slider

#### Appearance

| Prop      | Type                           | Default   |
| --------- | ------------------------------ | --------- |
| `variant` | `"solid" \| "soft"`            | `"solid"` |
| `size`    | `"sm" \| "md" \| "lg"`         | `"md"`    |
| `theme`   | `"gray" \| "accent" \| string` | `"gray"`  |

`variant`, `size` and `theme` flow to the parts through context. A prop on a part wins.

#### Structure

| Prop          | Type                         | Default        |
| ------------- | ---------------------------- | -------------- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |

### SliderTrack

| Prop   | Type                   | Default |
| ------ | ---------------------- | ------- |
| `size` | `"sm" \| "md" \| "lg"` | context |

### SliderIndicator

| Prop      | Type                           | Default |
| --------- | ------------------------------ | ------- |
| `variant` | `"solid" \| "soft"`            | context |
| `theme`   | `"gray" \| "accent" \| string` | context |

### SliderThumb

| Prop    | Type                           | Default |
| ------- | ------------------------------ | ------- |
| `size`  | `"sm" \| "md" \| "lg"`         | context |
| `theme` | `"gray" \| "accent" \| string` | context |

Every thumb needs an accessible name. Pass `aria-label`, or `getAriaLabel` for a range.

### CSS custom properties

| Property          | Description                                                                             |
| ----------------- | --------------------------------------------------------------------------------------- |
| `--slider-height` | Track thickness. Defaults to `--spacing(1)`, `--spacing(2)` and `--spacing(3)` by size. |

### Data slots

`slider`, `slider-label`, `slider-value`, `slider-control`, `slider-track`, `slider-indicator`, `slider-thumb`.

All other props are forwarded to the underlying [Base UI Slider](https://base-ui.com/react/components/slider) primitive.
