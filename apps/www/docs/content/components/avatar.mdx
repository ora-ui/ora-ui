## Usage

```tsx
import { Avatar, AvatarImage, AvatarFallback } from '@/registry/ui/avatar';

<Avatar>
  <AvatarImage src="..." alt="User avatar" />
  <AvatarFallback>AB</AvatarFallback>
</Avatar>;
```

## Examples

### Default

Renders an avatar with an image and a text fallback shown while the image loads or if it fails.

Use `AvatarBadge` to overlay a status indicator on the avatar.

Use `AvatarGroup` to stack multiple avatars with a negative offset. Add `AvatarGroupCount` to display an overflow count.
