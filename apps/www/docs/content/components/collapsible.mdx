## Usage

```tsx
import { Collapsible, CollapsibleContent, CollapsibleTrigger } from '@/registry/ui/collapsible';

<Collapsible>
  <CollapsibleTrigger>Show details</CollapsibleTrigger>
  <CollapsibleContent>Your plan renews on the first of each month.</CollapsibleContent>
</Collapsible>;
```

## Examples

### Variant

Set `variant` on the root to style the trigger. The `soft` trigger fills a square background.

<ComponentPreview name="collapsible-variants" select={['underline', 'soft']} />

### Icon position

Set `iconPosition` on the trigger to move the chevron to the start or the end.

<ComponentPreview name="collapsible-icon-position" select={['end', 'start']} />

### Custom icon

Add children with `data-slot="collapsible-trigger-icon"` to replace the chevron. Set `data-when` to `collapsed` or `expanded` to show an icon in one state only.

<ComponentPreview name="collapsible-custom-icon" />

### Button trigger

Pass an Ora Button to the `render` prop to use it as the trigger. The trigger's row classes merge into the Button, so override the ones you don't want with `className`.

<ComponentPreview name="collapsible-button-trigger" />

### Hidden until found

Set `hiddenUntilFound` on the content so find-in-page can reveal a closed panel.

<ComponentPreview name="collapsible-hidden-until-found" />

## API Reference

### Collapsible

| Prop      | Type                    | Default       |
| --------- | ----------------------- | ------------- |
| `variant` | `'underline' \| 'soft'` | `'underline'` |

### CollapsibleTrigger

| Prop           | Type               | Default |
| -------------- | ------------------ | ------- |
| `iconPosition` | `'start' \| 'end'` | `'end'` |

The parts carry `data-slot` values `collapsible`, `collapsible-trigger` and `collapsible-content`. The root sets `data-variant` and the trigger sets `data-icon-position`. The default chevron is `collapsible-trigger-icon-default`, and a custom icon uses `collapsible-trigger-icon`. `className` on the content applies to its inner padding wrapper. The content animates its height from the `--collapsible-panel-height` property that Base UI sets on the panel.

All other props are forwarded to the underlying [Base UI Collapsible](https://base-ui.com/react/components/collapsible) primitive.
