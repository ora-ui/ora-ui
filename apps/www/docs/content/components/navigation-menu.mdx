## Usage

```tsx
import {
  NavigationMenu,
  NavigationMenuContent,
  NavigationMenuItem,
  NavigationMenuLink,
  NavigationMenuList,
  NavigationMenuTrigger,
  NavigationMenuViewport,
} from '@/registry/ui/navigation-menu';

<NavigationMenu>
  <NavigationMenuList>
    <NavigationMenuItem>
      <NavigationMenuTrigger>Products</NavigationMenuTrigger>
      <NavigationMenuContent>
        <NavigationMenuLink href="#">Analytics</NavigationMenuLink>
      </NavigationMenuContent>
    </NavigationMenuItem>
    <NavigationMenuItem>
      <NavigationMenuLink href="#">Pricing</NavigationMenuLink>
    </NavigationMenuItem>
  </NavigationMenuList>
  <NavigationMenuViewport />
</NavigationMenu>;
```

## Examples

### Links only

Plain links need no panel. Set `active` on the link for the current page. To use a router link, pass it to `render`, for example `render={<Link href="/pricing" />}`.

<ComponentPreview name="navigation-menu-links-only" />

### Nested

A panel can hold a second level of links inline, indented under their parent link, with a heading above each group.

<ComponentPreview name="navigation-menu-nested" />

### Large menu

A tall panel is capped at `--available-height` and scrolls natively inside the popup. Ora does not use `ScrollArea` here.

<ComponentPreview name="navigation-menu-large-menu" />

### Vertical

Set `orientation="vertical"` on `NavigationMenu`, and place the popup beside the list with `side="right"` on `NavigationMenuViewport`.

<ComponentPreview name="navigation-menu-vertical" />

## API Reference

### NavigationMenu

| Prop          | Type                         | Default        |
| ------------- | ---------------------------- | -------------- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |

### NavigationMenuViewport

#### Structure

| Prop          | Type                                                                       | Default    |
| ------------- | -------------------------------------------------------------------------- | ---------- |
| `side`        | `"top" \| "bottom" \| "left" \| "right" \| "inline-start" \| "inline-end"` | `"bottom"` |
| `sideOffset`  | `number`                                                                   | `8`        |
| `align`       | `"start" \| "center" \| "end"`                                             | `"start"`  |
| `alignOffset` | `number`                                                                   | `0`        |

### NavigationMenuLink

| Prop           | Type      | Default |
| -------------- | --------- | ------- |
| `active`       | `boolean` | `false` |
| `closeOnClick` | `boolean` | `false` |

### Notes

- `NavigationMenuViewport` renders the portal, positioner, popup and viewport as one part. Place it inside `NavigationMenu`, beside `NavigationMenuList`.
- `NavigationMenuTrigger` renders a chevron. Put a `NavigationMenuIcon` inside it to replace the chevron.
- The popup animates with CSS transitions, so there is no need for `actionsRef` or `preventUnmountOnClose()`. Those are only for JavaScript animations. The size and position transitions are skipped under `prefers-reduced-motion`.

All other props are forwarded to the underlying [Base UI Navigation Menu](https://base-ui.com/react/components/navigation-menu) primitive.
