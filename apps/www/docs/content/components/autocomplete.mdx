## Usage

```tsx
import {
  Autocomplete,
  AutocompleteContent,
  AutocompleteEmpty,
  AutocompleteInput,
  AutocompleteInputGroup,
  AutocompleteItem,
  AutocompleteList,
} from '@/registry/ui/autocomplete';

const tags = ['Accessibility', 'Performance', 'Security'];

<Autocomplete items={tags}>
  <AutocompleteInputGroup>
    <AutocompleteInput aria-label="Tag" placeholder="Search tags" />
  </AutocompleteInputGroup>
  <AutocompleteContent>
    <AutocompleteEmpty>No tags found.</AutocompleteEmpty>
    <AutocompleteList>
      {(tag: string) => (
        <AutocompleteItem key={tag} value={tag}>
          {tag}
        </AutocompleteItem>
      )}
    </AutocompleteList>
  </AutocompleteContent>
</Autocomplete>;
```

## API Reference

### AutocompleteInputGroup

| Prop      | Type                               | Default     |
| --------- | ---------------------------------- | ----------- |
| `variant` | `'surface' \| 'outline' \| 'soft'` | `'surface'` |

`AutocompleteInputGroup` builds on `InputGroup`, and `variant` matches the `Input` variants. `AutocompleteInput` reuses the `Input` styles.

### AutocompleteContent

`AutocompleteContent` renders the portal, positioner and popup in one part. Its appearance props reach every `AutocompleteItem` and `AutocompleteList` inside it through context.

#### Appearance

| Prop      | Type                                   | Default         |
| --------- | -------------------------------------- | --------------- |
| `variant` | `'soft' \| 'solid'`                    | `'soft'`        |
| `theme`   | `'gray' \| 'accent' \| (string & {})`  | `'gray'`        |
| `density` | `'none' \| 'compact' \| 'comfortable'` | `'comfortable'` |

#### Structure

| Prop          | Type                                                                       | Default    |
| ------------- | -------------------------------------------------------------------------- | ---------- |
| `side`        | `'top' \| 'bottom' \| 'left' \| 'right' \| 'inline-start' \| 'inline-end'` | `'bottom'` |
| `sideOffset`  | `number`                                                                   | `4`        |
| `align`       | `'start' \| 'center' \| 'end'`                                             | `'start'`  |
| `alignOffset` | `number`                                                                   | `0`        |

### Styling hooks

`AutocompleteContent` sizes itself with the Base UI `--anchor-width` and `--available-height` properties, and `AutocompleteItem` rounds with `--menu-item-radius`. Each part sets `data-slot="autocomplete-<part>"`, for example `autocomplete-input-group`, `autocomplete-input` and `autocomplete-item`.

All other props are forwarded to the underlying [Base UI Autocomplete](https://base-ui.com/react/components/autocomplete#api-reference) primitive.
