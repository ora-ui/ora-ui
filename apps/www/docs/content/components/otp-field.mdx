## Usage

```tsx
import { OTPField, OTPFieldInput, OTPFieldSeparator } from '@/registry/ui/otp-field';

<OTPField length={6}>
  {Array.from({ length: 6 }, (_, index) => (
    <OTPFieldInput key={index} />
  ))}
</OTPField>;
```

## API Reference

### OTPField

| Prop      | Type                               | Default     |
| --------- | ---------------------------------- | ----------- |
| `variant` | `"surface" \| "outline" \| "soft"` | `"surface"` |

`variant` passes to every `OTPFieldInput` inside. A `variant` set on a slot wins.

All other props are forwarded to the underlying [Base UI OTP Field](https://base-ui.com/react/components/otp-field) primitive.

Set `--otp-slot-size` on `OTPField` to change the slot width and height. It defaults to `2.5rem`. Parts carry `data-slot="otp-field"`, `"otp-field-input"` and `"otp-field-separator"`. The root sets `data-complete` when every slot is filled.

### OTPFieldInput

| Prop      | Type                               | Default                |
| --------- | ---------------------------------- | ---------------------- |
| `variant` | `"surface" \| "outline" \| "soft"` | The `OTPField` variant |

All other props are forwarded to the underlying Base UI OTP Field Input primitive.

### OTPFieldSeparator

All props are forwarded to the underlying Base UI Separator primitive.
