## Usage

```tsx
import {
  ContextMenu,
  ContextMenuContent,
  ContextMenuGroup,
  ContextMenuItem,
  ContextMenuLabel,
  ContextMenuSeparator,
  ContextMenuTrigger,
} from '@/registry/ui/context-menu';

<ContextMenu>
  <ContextMenuTrigger>Right click here</ContextMenuTrigger>
  <ContextMenuContent>
    <ContextMenuGroup>
      <ContextMenuLabel>Section</ContextMenuLabel>
      <ContextMenuItem>Item</ContextMenuItem>
    </ContextMenuGroup>
    <ContextMenuSeparator />
    <ContextMenuItem>Another item</ContextMenuItem>
  </ContextMenuContent>
</ContextMenu>;
```

## API Reference

### ContextMenuContent

#### Appearance

| Prop      | Type                           | Default  |
| --------- | ------------------------------ | -------- |
| `variant` | `"soft" \| "solid"`            | `"soft"` |
| `theme`   | `"gray" \| "accent" \| string` | `"gray"` |

#### Structure

| Prop          | Type                                                                       | Default                              |
| ------------- | -------------------------------------------------------------------------- | ------------------------------------ |
| `side`        | `"top" \| "bottom" \| "left" \| "right" \| "inline-start" \| "inline-end"` | `"bottom"` (submenu: `"inline-end"`) |
| `align`       | `"start" \| "center" \| "end"`                                             | `"start"`                            |
| `sideOffset`  | `number`                                                                   | Base UI default                      |
| `alignOffset` | `number`                                                                   | Base UI default                      |

`ContextMenuSubContent` takes the same props and inherits `variant` and `theme` from the parent content. Its defaults are `side="inline-end"`, `align="start"`, `sideOffset={0}` and `alignOffset={-3}`.

### ContextMenuItem

| Prop      | Type                         | Default     |
| --------- | ---------------------------- | ----------- |
| `variant` | `"default" \| "destructive"` | `"default"` |
| `inset`   | `boolean`                    | `false`     |

`ContextMenuLabel`, `ContextMenuCheckboxItem`, `ContextMenuRadioItem`, `ContextMenuSubTrigger` and `ContextMenuSeparator` also take `inset`.

Content and item styling reads `--menu-item-radius` and `--menu-item-highlight-text`, set on `[data-slot="context-menu-content"]` and `[data-slot="context-menu-sub-content"]`. Parts carry `data-slot` names of the form `context-menu-<part>`.

All other props are forwarded to the underlying [Base UI Context Menu](https://base-ui.com/react/components/context-menu) primitive. The trigger is a plain `div`, so keyboard users open the menu with the context-menu key or Shift+F10 while it has focus.
