## Usage

```tsx
import {
  Progress,
  ProgressIndicator,
  ProgressLabel,
  ProgressTrack,
  ProgressValue,
} from '@/registry/ui/progress';

<Progress value={60}>
  <ProgressLabel>Uploading files</ProgressLabel>
  <ProgressValue />
  <ProgressTrack>
    <ProgressIndicator />
  </ProgressTrack>
</Progress>;
```

`ProgressLabel` names the progress bar for assistive technology. If you leave it out, pass `aria-label` to `Progress`.

## Examples

### Variants

The `variant` prop sets the indicator fill. `solid` is the full-contrast fill and `soft` is a lower-contrast one.

<ComponentPreview name="progress-variants" select={['solid', 'soft']} />

### Sizes

The `size` prop sets the track height.

<ComponentPreview name="progress-sizes" select={['sm', 'md', 'lg']} />

### Themes

The `theme` prop applies a color scheme to the indicator. The track stays neutral.

<ComponentPreview
  name="progress-themes"
  select={['gray', 'accent', 'destructive', 'warning', 'success']}
/>

### Indeterminate

Pass `value={null}` when the amount of work is unknown. The indicator fills the track and pulses, so it never reads as a value.

<ComponentPreview name="progress-indeterminate" />

### Status

Set `theme` from the task's state, such as `accent` while it runs and `success` once it finishes. Progress doesn't switch theme on its own when it completes.

## API Reference

### Progress

#### Appearance

| Prop      | Type                                                                      | Default   |
| --------- | ------------------------------------------------------------------------- | --------- |
| `variant` | `"solid" \| "soft"`                                                       | `"solid"` |
| `size`    | `"sm" \| "md" \| "lg"`                                                    | `"md"`    |
| `theme`   | `"gray" \| "accent" \| "destructive" \| "warning" \| "success" \| string` | `"gray"`  |

`Progress` passes `size` to `ProgressTrack`, and `variant` and `theme` to `ProgressIndicator`. Set them on a part to override the root. The track stays neutral in every theme.

### ProgressTrack

| Prop   | Type                   | Default |
| ------ | ---------------------- | ------- |
| `size` | `"sm" \| "md" \| "lg"` | Root    |

### ProgressIndicator

| Prop      | Type                                                                      | Default |
| --------- | ------------------------------------------------------------------------- | ------- |
| `variant` | `"solid" \| "soft"`                                                       | Root    |
| `theme`   | `"gray" \| "accent" \| "destructive" \| "warning" \| "success" \| string` | Root    |

### Styling

Set `--progress-height` on `ProgressTrack` or any ancestor to override the `size` height (`sm` 4px, `md` 8px, `lg` 12px). The parts set `data-slot` to `progress`, `progress-label`, `progress-value`, `progress-track` and `progress-indicator`.

All other props, including `value`, `min`, `max`, `format`, `locale` and `getAriaValueText`, are forwarded to the underlying [Base UI Progress](https://base-ui.com/react/components/progress) primitive.
