## Usage

```tsx
import { Center } from '@/registry/ui/center';

<Center>…</Center>;
```

Center sets `display: grid` and `place-items: center`. Style everything else with Tailwind utilities in `className`.

## API Reference

### Center

| Prop        | Type                 | Default |
| ----------- | -------------------- | ------- |
| `render`    | `React.ReactElement` | `<div>` |
| `className` | `string`             | —       |

All other props are forwarded to the rendered element.
