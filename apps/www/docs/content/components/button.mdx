## Usage

```tsx
import { Button } from '@/registry/ui/button';

<Button>Button</Button>;
```

## Examples

### Variants

The `variant` prop controls the visual style of the button.

<ComponentPreview
  name="button-variants"
  select={['solid', 'outline', 'surface', 'soft', 'ghost']}
/>

### Theme

The `theme` prop applies a color scheme across all variants.

<ComponentPreview name="button-theme" select={['gray', 'accent', 'destructive']} />

### With icon

Icons can be placed alongside button text. The button handles icon sizing automatically.

<ComponentPreview
  name="button-with-icon"
  select={[
    { label: 'Leading', value: 'leading' },
    { label: 'Trailing', value: 'trailing' },
  ]}
/>

### Icon button

Use `size="icon"` for icon-only buttons.

<Callout variant="warning" title="Accessibility">
  Always provide an `aria-label` on icon-only buttons. Without visible text, screen readers have no
  way to describe the button's purpose.
</Callout>

## Props

| Prop        | Type                                                     | Default   |
| ----------- | -------------------------------------------------------- | --------- |
| `variant`   | `"solid" \| "outline" \| "surface" \| "soft" \| "ghost"` | `"solid"` |
| `theme`     | `"gray" \| "accent" \| "destructive"`                    | `"gray"`  |
| `className` | `string`                                                 | —         |

All other props are forwarded to the underlying [Base UI Button](https://base-ui.com/components/button) primitive.
