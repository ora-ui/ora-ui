## Usage

```tsx
import {
  NumberField,
  NumberFieldGroup,
  NumberFieldDecrement,
  NumberFieldInput,
  NumberFieldIncrement,
} from '@/registry/ui/number-field';

<NumberField defaultValue={1}>
  <NumberFieldGroup>
    <NumberFieldDecrement />
    <NumberFieldInput />
    <NumberFieldIncrement />
  </NumberFieldGroup>
</NumberField>;
```

## Examples

### Variants

The `variant` prop controls the visual style of the field. It matches the variants of [Input](/docs/components/input).

<ComponentPreview name="number-field-variants" select={['surface', 'outline', 'soft']} />

### Range

Set `min` and `max` to limit the value. The buttons disable at the limits.

<ComponentPreview name="number-field-range" />

### Step

Set `step` to change how far each press moves the value. Hold Shift for `largeStep` and Alt for `smallStep`.

<ComponentPreview name="number-field-step" />

### Format

Pass `format` with `Intl.NumberFormat` options, and `locale` to pick the locale.

<ComponentPreview name="number-field-format" />

### Scrub

Wrap a label in `NumberFieldScrubArea` so that dragging it changes the value. `NumberFieldScrubAreaCursor` replaces the pointer while dragging.

<ComponentPreview name="number-field-scrub" />

### Field

Use the field inside `Field` to get a label, a description and an error message. The group shows the invalid state.

<ComponentPreview name="number-field-field" />

### Disabled

Set `disabled` to stop all interaction.

<ComponentPreview name="number-field-disabled" />

## API Reference

### NumberField

#### Appearance

| Prop      | Type                               | Default     |
| --------- | ---------------------------------- | ----------- |
| `variant` | `"surface" \| "outline" \| "soft"` | `"surface"` |

`variant` flows to `NumberFieldGroup`, `NumberFieldDecrement` and `NumberFieldIncrement` through context. A `variant` set on a part wins.

All other props are forwarded to the underlying [Base UI Number Field](https://base-ui.com/react/components/number-field) primitive.

### NumberFieldGroup

| Prop      | Type                               | Default                  |
| --------- | ---------------------------------- | ------------------------ |
| `variant` | `"surface" \| "outline" \| "soft"` | `variant` of NumberField |

### NumberFieldDecrement and NumberFieldIncrement

| Prop      | Type                               | Default                  |
| --------- | ---------------------------------- | ------------------------ |
| `variant` | `"surface" \| "outline" \| "soft"` | `variant` of NumberField |

The buttons reflect `variant` as `data-variant`. They render an Ora [Button](/docs/components/button) with the `ghost` variant and the `icon` size.

### Other parts

`NumberFieldInput`, `NumberFieldScrubArea` and `NumberFieldScrubAreaCursor` forward their props to the matching Base UI part.

Each part sets `data-slot` to `number-field-<part>`, for example `number-field-group`.
