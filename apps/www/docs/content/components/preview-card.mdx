## Usage

```tsx
import { Link } from '@/registry/ui/link';
import { PreviewCard, PreviewCardContent, PreviewCardTrigger } from '@/registry/ui/preview-card';

<PreviewCard>
  <PreviewCardTrigger render={<Link href="https://ora-ui.com" />}>Ora UI</PreviewCardTrigger>
  <PreviewCardContent>Styled primitives for building accessible interfaces.</PreviewCardContent>
</PreviewCard>;
```

<Callout variant="warning" title="Accessibility">
  The card opens on mouse hover and keyboard focus only. Touch devices and screen readers never see
  it, so it must not hold anything the reader needs that the link's own page does not repeat.
</Callout>

## Examples

### Placement

Set `side` and `align` on `PreviewCardContent` to choose where the card opens. It flips to the opposite side when there is no room.

<ComponentPreview name="preview-card-placement" select={['bottom', 'top', 'right', 'left']} />

### Delay

Set `delay` and `closeDelay` on `PreviewCardTrigger` to tune the timing. The card opens after 600ms by default.

<ComponentPreview name="preview-card-delay" />

### Inline

A link inside a paragraph of text opens a card when hovered or focused.

## API Reference

### PreviewCardContent

#### Structure

| Prop          | Type                                                                       | Default    |
| ------------- | -------------------------------------------------------------------------- | ---------- |
| `side`        | `"top" \| "right" \| "bottom" \| "left" \| "inline-start" \| "inline-end"` | `"bottom"` |
| `sideOffset`  | `number`                                                                   | `4`        |
| `align`       | `"start" \| "center" \| "end"`                                             | `"center"` |
| `alignOffset` | `number`                                                                   | `0`        |

`PreviewCardTrigger` renders an unstyled `<a>`. Compose it with Ora's `Link` through `render`.

The card is `w-64` with `p-3` padding. Override either with `className`.

Slots are `preview-card`, `preview-card-trigger` and `preview-card-content`.

All other props are forwarded to the underlying [Base UI Preview Card](https://base-ui.com/react/components/preview-card) primitive.
