## Usage

```tsx
import { Meter, MeterIndicator, MeterLabel, MeterTrack, MeterValue } from '@/registry/ui/meter';

<Meter value={24}>
  <MeterLabel>Storage used</MeterLabel>
  <MeterValue />
  <MeterTrack>
    <MeterIndicator />
  </MeterTrack>
</Meter>;
```

`MeterLabel` names the meter for assistive technology. If you leave it out, pass `aria-label` to `Meter`.

## Examples

### Variants

The `variant` prop sets the indicator fill. `solid` is the full-contrast fill and `soft` is a lower-contrast one.

<ComponentPreview name="meter-variants" select={['solid', 'soft']} />

### Sizes

The `size` prop sets the track height.

<ComponentPreview name="meter-sizes" select={['sm', 'md', 'lg']} />

### Themes

The `theme` prop applies a color scheme to the indicator. The track stays neutral.

<ComponentPreview
  name="meter-themes"
  select={['gray', 'accent', 'destructive', 'warning', 'success']}
/>

### Range and format

Set `min` and `max` for a range other than 0 to 100, and `format` to show the value in its own unit. Pass a function to `MeterValue` to add text around the formatted value.

<ComponentPreview name="meter-range" />

### Thresholds

Set `theme` from the value, such as `warning` past 75% and `destructive` past 90%. Meter doesn't switch theme on its own.

## API Reference

### Meter

#### Appearance

| Prop      | Type                                                                      | Default   |
| --------- | ------------------------------------------------------------------------- | --------- |
| `variant` | `"solid" \| "soft"`                                                       | `"solid"` |
| `size`    | `"sm" \| "md" \| "lg"`                                                    | `"md"`    |
| `theme`   | `"gray" \| "accent" \| "destructive" \| "warning" \| "success" \| string` | `"gray"`  |

`Meter` passes `size` to `MeterTrack`, and `variant` and `theme` to `MeterIndicator`. Set them on a part to override the root. The track stays neutral in every theme.

### MeterTrack

| Prop   | Type                   | Default |
| ------ | ---------------------- | ------- |
| `size` | `"sm" \| "md" \| "lg"` | Root    |

### MeterIndicator

| Prop      | Type                                                                      | Default |
| --------- | ------------------------------------------------------------------------- | ------- |
| `variant` | `"solid" \| "soft"`                                                       | Root    |
| `theme`   | `"gray" \| "accent" \| "destructive" \| "warning" \| "success" \| string` | Root    |

### Styling

The track is 4px tall at `sm`, 8px at `md` and 12px at `lg`. The parts set `data-slot` to `meter`, `meter-label`, `meter-value`, `meter-track` and `meter-indicator`.

All other props, including `value`, `min`, `max`, `format`, `locale` and `getAriaValueText`, are forwarded to the underlying [Base UI Meter](https://base-ui.com/react/components/meter) primitive.
