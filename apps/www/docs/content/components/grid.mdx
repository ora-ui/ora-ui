## Usage

```tsx
import { Grid } from '@/registry/ui/grid';

<Grid className="gap-4">…</Grid>;
```

Grid sets `display: grid`. Style everything else with Tailwind utilities in `className`.

## API Reference

### Grid

| Prop        | Type                 | Default |
| ----------- | -------------------- | ------- |
| `render`    | `React.ReactElement` | `<div>` |
| `className` | `string`             | —       |

All other props are forwarded to the rendered element.
