## Usage

```tsx
import {
  Combobox,
  ComboboxContent,
  ComboboxEmpty,
  ComboboxInput,
  ComboboxInputGroup,
  ComboboxItem,
  ComboboxList,
  ComboboxTrigger,
} from '@/registry/ui/combobox';

const fruits = ['Apple', 'Banana', 'Cherry'];

<Combobox items={fruits}>
  <ComboboxInputGroup>
    <ComboboxInput aria-label="Fruit" placeholder="Select a fruit" />
    <ComboboxTrigger />
  </ComboboxInputGroup>
  <ComboboxContent>
    <ComboboxEmpty>No fruits found.</ComboboxEmpty>
    <ComboboxList>
      {(item: string) => (
        <ComboboxItem key={item} value={item}>
          {item}
        </ComboboxItem>
      )}
    </ComboboxList>
  </ComboboxContent>
</Combobox>;
```

## API Reference

### ComboboxInputGroup

| Prop      | Type                               | Default     |
| --------- | ---------------------------------- | ----------- |
| `variant` | `'surface' \| 'outline' \| 'soft'` | `'surface'` |

`ComboboxInputGroup` builds on `InputGroup`, and `variant` matches the `Input` variants. `ComboboxInput` reuses the `Input` styles.

### ComboboxContent

`ComboboxContent` renders the portal, positioner and popup in one part. Its appearance props reach every `ComboboxItem` and `ComboboxList` inside it through context.

#### Appearance

| Prop      | Type                                   | Default         |
| --------- | -------------------------------------- | --------------- |
| `variant` | `'soft' \| 'solid'`                    | `'soft'`        |
| `theme`   | `'gray' \| 'accent' \| (string & {})`  | `'gray'`        |
| `density` | `'none' \| 'compact' \| 'comfortable'` | `'comfortable'` |

#### Structure

| Prop          | Type                                                                       | Default    |
| ------------- | -------------------------------------------------------------------------- | ---------- |
| `side`        | `'top' \| 'bottom' \| 'left' \| 'right' \| 'inline-start' \| 'inline-end'` | `'bottom'` |
| `sideOffset`  | `number`                                                                   | `4`        |
| `align`       | `'start' \| 'center' \| 'end'`                                             | `'start'`  |
| `alignOffset` | `number`                                                                   | `0`        |

### Styling hooks

`ComboboxContent` sizes itself with the Base UI `--anchor-width` and `--available-height` properties, and `ComboboxItem` rounds with `--menu-item-radius`. Each part sets `data-slot="combobox-<part>"`, for example `combobox-input-group`, `combobox-chip` and `combobox-item`.

All other props are forwarded to the underlying [Base UI Combobox](https://base-ui.com/react/components/combobox#api-reference) primitive.
